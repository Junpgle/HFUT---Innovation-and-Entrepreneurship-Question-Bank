# 题库系统

在线题库练习系统

## 主要功能

### 核心功能
- 📚 **题库练习** - 支持单选、多选、判断三种题型
- 🧠 **背题模式** - 直接查看答案和解析，快速记忆
- ❌ **错题本** - 自动记录错题，针对性复习
- 📊 **数据统计** - 详细的学习进度和正确率统计
- ☁️ **云端同步** - 登录后支持跨设备数据同步
- 📱 **响应式设计** - 完美适配手机、平板和电脑

### 新增功能 (v3.2.0)

#### 🔍 题库搜索功能 (NEW!)
- **关键词搜索** - 在题目内容、选项和解析中快速查找
- **高级筛选** - 按章节、题型、答题状态筛选
- **智能匹配** - 不区分大小写，支持模糊匹配
- **快速练习** - 直接从搜索结果开始练习

#### 🏆 易错题排行榜
- 查看全站最易错的题目
- 了解常见错误和难点
- 针对性加强练习

#### 👥 用户共建解析
- 为暂无解析的题目贡献解析
- 查看其他用户的解析
- 投票支持优质解析

#### 💬 评论区
- 对题目进行讨论
- 分享解题思路
- 交流学习心得

## 章节内容

系统包含以下7个讲次的题目：
1. 第一讲：创新创业概述
2. 第二讲：创新思维与方法
3. 第三讲：机会与风险识别
4. 第四讲：团队与资源整合
5. 第五讲：商业模式与计划
6. 第六讲：融资与企业设立
7. 第七讲：新企业成长管理

## 技术栈

- **前端框架**: React 19
- **构建工具**: Vite 7
- **样式**: Tailwind CSS 3
- **图标**: Lucide React
- **后端**: LeanCloud (BaaS)
- **Excel解析**: XLSX.js
- **本地存储**: LocalForage + LocalStorage

## 快速开始

### 在线使用
直接访问部署的网站即可使用，支持游客模式和登录模式。

### 本地开发

1. 克隆仓库
```bash
git clone https://github.com/Junpgle/HFUT---Innovation-and-Entrepreneurship-Question-Bank.git
cd HFUT---Innovation-and-Entrepreneurship-Question-Bank/hfut-quiz
```

1. 安装依赖
```bash
npm install
```

1. 启动开发服务器
```bash
npm run dev
```

1. 构建生产版本
```bash
npm run build
```

1. 预览生产构建
```bash
npm run preview
```

## 使用指南

### 基本操作

1. **开始练习**
   - 选择章节（或综合练习）
   - 设置题目数量
   - 选择题型（单选/多选/判断/全部）
   - 选择模式（随机/未做/错题）
   - 点击"开始刷题"或"背题模式"

2. **搜索题目** (NEW!)
   - 在搜索框输入关键词
   - 使用筛选器精确定位
   - 点击结果开始练习

3. **错题复习**
   - 点击"错题攻坚"卡片
   - 系统自动加载所有错题
   - 随机打乱顺序练习

4. **查看统计**
   - 点击"数据报表"查看详细统计
   - 了解学习进度和薄弱环节

### 登录功能

登录后可享受：
- 云端数据备份
- 跨设备同步
- 社区互动（评论、贡献解析）
- 易错题排行榜

- 本地数据存储在浏览器的IndexedDB和LocalStorage中
- 云端数据通过LeanCloud加密传输和存储
- 支持手动备份和恢复
- 可随时重置本地进度
